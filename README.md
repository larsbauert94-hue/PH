# Ringfahrt

Ein rundenbasiertes Action-RPG im Browser mit Figuren aus Tolkiens Mittelerde (inoffizielles Fan-Projekt).

**Spielen:** `index.html` im Browser öffnen. Keine Installation, kein Build.

## Features
- **8 spielbare Gefährten** (Aragorn, Legolas, Gimli, Gandalf, Frodo, Samweis, Boromir, Éowyn), je 4 Fähigkeiten + Ultimate
- **Timing-Angriffe & Paraden** (Leertaste / Tippen) wie in Paper Mario oder Clair Obscur
- **Geschwindigkeitsbasierte Zugreihenfolge** mit Vorschau (à la Final Fantasy X)
- **Kapitelkarte mit Weggabelungen** (Kampf, Elite, Begegnung, Lagerfeuer, Händler) wie in Slay the Spire
- **8 Kapitel** vom Auenland bis zum Schicksalsberg, Bosse: Schwarzer Reiter, Ringgeister, Balrog, Lurtz, Saruman, Kankra, Hexenkönig, Sauron
- Statuseffekte, Ultimate-Leiste, Stufenaufstiege, Gegenstände, Schmied, Frodos Ringlast
- 3 Schwierigkeitsgrade, Auto-Timing-Option, automatisches Speichern (localStorage)
